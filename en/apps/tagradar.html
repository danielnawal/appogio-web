BLE Asset Tracking

Know where every asset is, always.

TagRadar uses long-life BLE tags detected by fixed or mobile antennas. The map shows in real time the last antenna that detected each asset. No GPS, no SIM: works indoors, in yards and warehouses where GPS doesn't reach.

Features

From inventory chaos to total control

Last position by antenna

Each BLE tag is captured by the nearest antenna. The map shows in real time the position of the antenna that last detected it, updated every 20 seconds.

Geofences with entry/exit alerts

Define zones for each asset or group. Receive an immediate alert when equipment enters or leaves the assigned area. Configurable per zone and asset.

24-hour route history

Query the complete detection history of any asset in the last 24 hours: the antenna that saw it, exact time and position. Total traceability.

Real-time asset states

Live (detected <5 min ago), Recent (<2 h) or Inactive (>2 h). At a glance you know which assets are being monitored and which haven’t reported in a while.

Asset and antenna management

Register, edit and delete tags with name and description. Check which antennas are active, when they last reported and how many assets they've detected.

Android app + SSO with Appogio

Access from the native Android app with the same GPS Software credentials. Antennas report via BLE scanner APK without additional hardware.
